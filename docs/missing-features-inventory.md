## 7 · 移植风险与前置约束

1. **`api/freeImageHostApi.js` 绝不能被覆盖** —— 工作区那份是你未提交的手写可读版（md5 `1e0458013f5341c99f21faefc1d34d3f`）。新版目录里**同名文件存在**，任何批量复制必须显式排除。
2. **不能全量搬运** —— 1,055 个 `src/` 新文件 + 144 个 `api/` 新文件里，有相当一部分依赖 B 类不存在的后端接口；直接灌进来会把可读的树重新混入混淆代码，并引入 108 个不存在的接口。
3. **不可读的中间产物要隔离** —— 反混淆工作在 `C:\Users\luobote\.qoder\tmp\shuo-deobf\`（渲染层）、`shuo-electron-deobf\`（Electron）、`shuo-asar\`（asar 原始抽取）三处临时目录，**不要**混进 `F:\CanvasPro`。
4. **推送 `master` 会触发 macOS arm64 构建并 `gh release upload v0.4.12 --clobber`** —— 会覆盖已发布的 release 资产。本轮工作**不推送**。
5. **`styles/` 是架构级变更** —— 新版 `style.css` 只有 `@import` 清单，要搬必须把 214 个 CSS 文件**整目录**搬过去；只搬 `style.css` 会导致样式全丢。
