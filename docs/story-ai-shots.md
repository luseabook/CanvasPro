# 第六批：工作室 AI 分镜生成

源码接在第五批 AI 助手内，最初复用火山引擎文本接口；第九批扩展为现有多厂商文本适配，继续复用配置、鉴权和单请求占用锁，详见 `story-ai-providers.md`。没有新增后端接口、安装依赖、自动触发模型或生成媒体。第六批本身不是任务队列或成片导出；第七批另加多集串行队列与手动快照恢复，详见 `story-ai-queue.md`。

## 入口和操作

1. 打开剧本工作室，选择有正文的单集。
2. 点击 **AI 拆集 / 资料 / 分镜**，操作选 **AI 生成分镜（追加，不覆盖）**。
3. 设置目标镜数 1–32。可选填写创作要求，并选择本次允许发送的人物和场景文字资料（默认不选，Ctrl/Cmd 多选）。
4. 可点 **预览待发送文字（不请求模型）** 查看系统提示词和任务正文。此操作是本地拼装，不调用模型、不消耗模型额度。
5. 点击发送，确认厂商、模型、正文长度、所选资料数量和可能产生的费用。
6. 查看分镜表，展开逐镜字段和对应原文。可全选、取消全选或逐项勾选；可修正原始 JSON 后重新校验，不会自动重新请求模型。
7. 确认追加到草稿后，会打开当前集的分镜页并定位到首个新增镜头所在页。继续编辑，再 **应用到项目 → 原有工程保存**。
8. 使用原有“生成分镜脚本节点”流程创建画布快照，继续原有图像/视频操作。仅追加草稿不会自行创建节点或发起媒体生成。

## 上传边界

拆集/资料提取仍只上传当前集正文和固定任务说明。分镜模式额外上传本次选择的资料名称、文字描述以及创作要求。

不读取图片绑定和素材地址字段，不发送其他单集、项目梗概、内部资料 ID 或历史对话。所选描述本身若含敏感文本或手写 URL，它们会作为普通文字发送；请在发送内容预览中核对。

引用使用本次临时编号 `C1...` 和 `S1...`，在本地映射为已有资料 ID。模型不能靠编造名称或 ID 创建新资料、指向未选资料、修改绑定或覆盖人物/场景设定。未选择资料时，人物和场景引用为空；名称可以写在画面描述中，之后自行关联。

模型实际接收地址仍由原有项目配置决定，包括用户设置的合法中转。模型账号和服务地址需事先配置。API Key 不写入工作室节点、发送内容预览或 AI 结果。

## 结构校验和保存

模型返回 `story-ai-shots.v1` JSON，镜数必须符合请求。每镜包含段落起止号、数字秒数、景别、画面描述、所选人物/场景引用，以及可选对白、动作、情绪、本镜人物补充、图像/视频提示词、音效。

- 0.1–120 秒/镜；这是建议时长，不保证下游图像/视频模型支持对应时长。
- 原文按空行编号。起止号不能越界或倒退，镜头之间不得跳过段落，结果的段落范围须覆盖全文；多个镜头可以引用同一段。
- **上述仅为结构校验，不证明模型完整或准确表现了原文。** 调度和提示词是创作建议；对白、事实、人物一致性须人工核对。未全选时，追加内容不再保证引用全文。
- 严格检查资料编号；不依据重名文字猜测引用关系。JSON 修正时可查看资料编号对照，也可展开待发送文字查看所选设定。
- 程序为新增镜头生成新 ID。只把白名单分镜字段写入现有 workspace schema，段落范围和临时编号只用于本次预览，不作为持久化溯源记录。
- 不改写单集正文，不替换旧镜头，不删除或覆盖资料；只按候选镜头原顺序追加勾选项。
- 来源画布/草稿、单集正文或所选设定改变时拒绝合并过期结果；整体规范化后才更新草稿。容量失败不部分写入。
- 保存后的时长、对白、动作、提示词、人物/场景引用继续走原分镜行映射。原画布桥接把已有图片绑定转换为 `@图片N` 与 `referenceImageRefs`，不是让 AI 伪造媒体引用。
- 重复生成/追加可能产生内容相似的镜头，本批不自动去重，也不覆盖旧镜头。

## 限制和失败处理

- 正文最多 40000 UTF-16 字符、400 段；单次 1–32 镜。
- 所选人物和场景各最多 20 项；每项描述最多 4000 字符，资料 JSON 合计最多 16000 字符；创作要求最多 1000 字符。
- 合成提示词最多 48000 字符，返回 JSON 最多 262144 字符。限制叠加，不能同时把所有字段填到各自上限。超限拒绝，不静默截断，不自动分批。
- 发送前检查完整目标镜数是否会超过单集 300 / 工作室 2000 镜；确认合并时重新检查所选数量和工作室 4MiB 总限制。
- 模型可能返回截断、非 JSON 或不符合约束的结果。保留可显示的原始响应供修正；过大响应不展示。不会自动请求“修复 JSON”或重发。
- 单请求占用锁、费用确认和放弃语义沿用第五批：**放弃结果不保证厂商停止执行或计费**；网络失败/超时先核对厂商记录，避免重发重复计费。
- 单次助手没有跨刷新恢复；第七批队列提供手动快照导出/导入，第八批支持明确启用的本地自动保存，见 `story-ai-queue-storage.md`。仍无自动图像/视频生成或影片合成。
