# 第二批缺失功能源码：ComfyUI 工作流节点

本批是在旧版项目中新增可读、可维护的实现，不是覆盖为 0.7.16 整包资源，也不是 RunningHub 自定义应用的完整实现。

## 使用

1. **重启当前项目的 Python 后端**，刷新源码版前端。无需重装依赖（使用已有 requests）。不会修改已安装的 SHUO Canvas。
2. 双击画布 → 功能节点 → **ComfyUI 工作流**。
3. 选择服务，必要时填写 Bearer Token，点击测试连接。
4. 在自己的 ComfyUI 导出 **API 格式 JSON**，导入节点。普通可视化工作流 JSON 不可执行，会明确报错。仅使用可信来源工作流；ComfyUI 自定义节点本身可能具有文件/进程权限。
5. 编辑提示词、种子、宽高等字符串/数字/布尔参数；连线不会被当作参数修改。标准 `LoadImage.image` 提供图片上传按钮（PNG/JPEG/WebP，8MB 上限）。服务端需已安装对应模型和自定义节点。
6. 提交后每 3 秒查询队列/历史。这里只展示任务状态、队列位置，不伪造采样百分比。
7. 完成后点击 **保存结果到画布**，下载受支持的图片/音频/视频，复用本地输出保存接口，再创建源媒体节点。失败时保留已成功结果，重试不会重复创建已有结果节点。

## 本地 / 云端服务配置

默认只允许 `http://127.0.0.1:8188` 与 `http://localhost:8188`。它们指的是 **Canvas Python 后端所在电脑**，不是远程访问者自己的电脑。

其他地址必须由部署者明确配置，示例（PowerShell，在启动 Canvas 后端的同一环境中）：

```powershell
$env:AIC_COMFYUI_ALLOWED_URLS = 'http://127.0.0.1:8190,https://your-comfy.example.com/comfy'
# 再使用项目原来的启动方式启动 Python 后端
```

使用真实服务地址替换示例。远程地址要求 HTTPS；不允许 URL 内嵌用户名/密码、查询参数、重定向。云端需兼容标准 ComfyUI API，并可通过 Bearer Token 访问；厂商私有登录流程和专有 API 暂不支持。

新代理沿用项目的本地访问令牌/Origin 校验，并将 `/api/v2/comfyui` 加入敏感路径范围。它不是可转发任意 URL/任意方法的开放代理。连接密钥仅在界面内存和当前请求中使用，不写入项目；离开节点/刷新后可能需重新填写。**用户导入的工作流本身若含密钥字段，仍属于其工作流数据，会随项目保存，分享前需检查。**

## 任务安全与恢复

- 提交前保存请求 ID，后端在当前进程内对同一请求去重；请求超时进入「状态待确认」，不会自动重发生成请求。
- 后端去重缓存最多 512 次提交，达到上限明确拒绝，不无声淘汰后重发。后端重启后该缓存不会保留。
- 查询恢复可按 `promptId`，或在队列/最近 100 条历史中查找请求 ID。历史清空或过旧时无法保证恢复，必须在 ComfyUI 核对，不能直接假定任务失败。
- 「取消排队任务」仅删除指定排队 ID，不调用全局 `/interrupt`。执行中的任务需在 ComfyUI 手动处理，界面会说明。
- 「暂停跟踪」只停止查询，不取消远端执行；「新任务 / 放弃跟踪」在任务可能仍运行时要求再次点击确认。
- 节点被虚拟化卸载、切换画布、刷新时停止前端查询，任务记录保留；重新打开后手动恢复，不自动重提。
- 项目撤销/重做仅还原本地数据，不回滚远端生成。已有任务不会因恢复项目而自动再次执行。
- 结果保存采用稳定节点 ID。关闭/切换画布时未完成的本地保存可能留下输出文件，但不会向另一画布写入错误节点。

## 源码与接口

- `backend/services/comfyui_route_service.py`：服务端适配器、地址白名单、状态/恢复/取消、输入上传、输出校验下载。
- `api/comfyWorkflowApi.js`：使用项目 requester，无自动生成重试。
- `src/modules/comfyui/comfyWorkflowModel.js`：工作流校验、参数编辑、默认节点数据、结果节点稳定 ID。
- `src/components/ComfyWorkflowNode.js`：节点 UI、任务流程、持久化、素材保存。
- `styles/comfy-workflow.css`：独立样式。
- `server.py` 增加路由接入；节点注册、元信息、菜单、工厂、默认尺寸、语言菜单与键盘作用域接入。

本地接口：GET `/api/v2/comfyui/connections`；POST `system-stats`、`prompt`、`history`、`recover`、`cancel`、`view`、`upload`。密钥通过请求体传递，不出现在查询串中。输出下载只能选指定任务历史里列出的媒体，不接受任意服务器文件路径。

## 当前边界

- 支持至多 500 个工作流节点、2MB JSON；参数支持基本类型和标准 `[nodeId, slot]` 连线。复杂对象参数、多文件自定义上传组件不在本批。
- JSON 响应上限 8MB，单个媒体结果上限 64MB；响应体超限报错。历史中最多列出前 200 个受支持的输出，其余输出请在 ComfyUI 获取。
- GIF 按图像素材加入，动画呈现取决于旧版源图像节点能力。
- 本批节点内部提示主要为中文；中英文创建菜单均已接入。
- 未添加 ComfyUI WebSocket 采样进度、自动安装模型、厂商专有云端协议、跨画布持续后台执行或所有 0.7.16 自定义应用功能。
