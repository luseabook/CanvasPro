# 缺失功能补充 · 第一批：白板节点

这是直接集成到当前 0.4.12 项目的独立可读实现，不是 0.7.16 发布资源的整包覆盖，也不代表全部新版功能已补齐。

## 入口

双击空白画布，或使用现有添加节点入口，在「功能节点」中选择「白板」。右键创建菜单使用同一目录，也提供白板。

## 已接入源码

- 画笔、矩形、椭圆、直线、箭头、文字。
- 画笔颜色、笔宽、文字字号、图形填充；白色/自选/透明背景。
- PNG/JPEG/WebP 图片导入或拖入：原文件上限 8MB，最长边缩至 2048，嵌入经过解码的 PNG，不保存临时 blob URL。
- 图层选择、移动、置顶/置底、放大/缩小、删除；橡皮操作删除整层，并非像素橡皮。
- 每个完成的编辑操作写入项目现有全局历史，撤销/重做不单独维护另一套数据。
- 白板向量数据存储在节点的 `whiteboard` 字段，随现有项目 JSON 保存、恢复、复制；绘制中预览不写历史。
- PNG 导出（默认白板分辨率 1200×800）；生成图像节点通过已有 `saveOutputBlob` 后端保存，成功后再创建持久化源图像节点，可供后续模型引用。
- 节点移动使用外侧标题；右下角调整显示大小不改变白板逻辑坐标。
- UI 支持项目的中文/英文语言切换。编辑区域内 Delete/D 删除选中图层，避免误删整个白板节点。

## 结构

- `src/modules/whiteboard/whiteboardModel.js`：数据校验、不可变操作、几何与命中检测。
- `src/modules/whiteboard/whiteboardDrawing.js`：SVG 预览、Canvas PNG 绘制与图片解码。
- `src/components/WhiteboardNode.js`：节点生命周期、交互、历史/存储集成、导出。
- `styles/whiteboard.css`：仅白板作用域的样式，在挂载时通过模块 URL 加载，不替换原有大样式表。
- 修改节点注册、元信息、创建目录、创建工厂、默认尺寸、语言目录和键盘路由的少量接入点。

## 数据与兼容边界

白板数据结构是本项目新增的 `version: 1`，不是声称兼容新版软件所有白板私有字段。支持 500 层、每条笔迹 4000 点。导入图片随项目保存，会增大项目 JSON；大量高分辨率素材应继续使用项目原有素材节点。

没有改动授权校验、用户已有短剧实现、上传接口、更新源、数据库或安装版文件。没有使用临时绝对路径作为运行依赖。

## 验证状态

提供 `whiteboardModel.test.js` 供授权后执行。本批未启动应用、未调用模型、未执行测试套件或构建。

本次静态检查：14 个新增/修改的 JavaScript 文件通过 `node --check`；新模块的相对导入和样式路径全部存在；查询时编辑器 `src/` 范围错误诊断为 0。以上不等同于浏览器/桌面端运行验收通过。

建议后续手动验收：

1. 双击/右键分别创建白板，画笔与图形在 50%/100%/200% 缩放下定位准确。
2. 添加文字，选中文字层、修改文字后 Enter 更新；切换中英文。
3. 图片导入/拖入，移动、缩放、调整图层顺序；删除再撤销/重做。
4. 保存项目，关闭再打开，确认图层仍可编辑；复制白板后修改副本不影响原件。
5. PNG 导出与预览一致，透明背景保留；「生成图像节点」断网/保存失败时不能出现假成功节点。
6. 在绘图中按 Esc/切换画布，确认取消预览、不出现悬挂监听；空格/中键仍能平移外层画布。
7. 回归旧节点创建、项目保存、画布 Delete/撤销等现有操作。
