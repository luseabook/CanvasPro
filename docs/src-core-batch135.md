## 2. 冻结的端口行为（写测试时的契约，摘要）

- **`viewportGridDots`**：背景位置和尺寸只在变化时写入；屏幕间距低于 18px 时按 2 倍递增；低缩放隐藏、高缩放强调，并缓存上次视口以避免重复写样式。
- **`rendererViewportMediaPreloadPause`**：暂停会以固定优先级暂停全局图片预加载；定时恢复前若页面仍处于平移、缩放或视口动画状态，则每 180ms 重查；显式清理会取消定时器并恢复。
- **`taskBatchExecution`**：取消控制器只允许首次请求成功；任务队列按上限并发、保持输入顺序产出，单任务异常记录为 `rejected`，停止谓词关闭后未启动项标为 `cancelled`。
- **`canvasZoom`**：缩放限制为 `0.05..4`；滚轮按指数变化并夹取；滑杆为 0–100 的对数映射；显示百分比允许从适配下限 1% 到最大 400%。
- **`stores/rendererStateRevisions`**：节点、成员关系、几何、源视频和渲染请求分别维护修订号；批量变更只提交一次；源视频仅在代理地址或版本签名变化时递增。
- **`spatialProjectionMath`**：客户端坐标与 NDC 双向换算；射线轴平面求交只接受轴索引并限制为正向前向距离；相机调整不修改输入，支持平移、旋转和相对位姿。
- **`rendererVideoHydrationBackpressure`**：优先工作建立冷却期，普通工作每帧最多获取一次；长帧或非优先工作被阻塞过久后放行；重置会取消挂起帧并恢复初始状态。
- **`rendererVirtualizationSignature`**：选中和固定节点先转字符串并排序；非有限值归一为 `null` 或 0；密集低缩放视口按 64px 或 96px 网格量化移动。
- **`viewportBoundaryMath`**：点可投影到带内边距的视口边缘并返回是否越界与角度；边界点铺开会避开已占位置，并限制在视口内。
- **`stores/graphMutationImpact`**：节点移动会连同子节点规划；删除节点会带出相连边上的节点；分组、边批处理和节点数据变更返回受影响节点；未知 mutation 抛错。
