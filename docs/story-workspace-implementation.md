# 第三批：剧本工作室编辑与画布互转

本批在旧项目中新增可维护源码，补齐**离线剧本编辑基础闭环**。不是安装版 0.7.16 的全部模块完整移植（早期141模块统计须复核），也不声明与其私有 JSON 格式兼容。未修改原有短剧后端、白板、ComfyUI 服务逻辑或模型生成接口。

## 入口与保存

刷新源码版前端后，双击画布 → 功能节点 → **剧本工作室** → **打开剧本工作室**。

- 工作室是画布中的 `story-workspace` 节点，打开原生模态编辑窗口。
- 编辑窗口中的修改先保留为草稿，点击 **应用到项目**（窗口内 Ctrl/Cmd+S 同义）才写入节点数据并创建画布历史记录。
- **应用到项目不等于工程已落盘**。关闭编辑窗口后，继续使用项目原有保存/自动保存机制。编辑窗口中的 Ctrl/Cmd+S 不触发全局保存动作。
- 已应用的修改可在关闭窗口后通过画布撤销/重做。文本输入框仍使用浏览器原生文本撤销。
- 关闭未应用草稿会二次确认；浏览器离开页提示为 best-effort，异常退出无法恢复未应用草稿。
- 若来源节点卸载或画布改变，未应用草稿会留在窗口供 JSON 导出，不写入其他画布。已应用版本仍在原节点中。
- 应用前比较源数据；如果原节点被其他操作修改，拒绝覆盖，提示先导出草稿再重载。不做静默合并。

## 已实现

1. **多集管理**：新建、复制、删除、排序、单集标题/正文及项目梗概。
2. **人物与场景资料**：名称、描述、绑定当前画布源图像节点。删除资料会解除对应分镜引用，不删除源图片。
3. **分镜表**：镜头新增/删除/排序、时长、景别、场景、人物多选、画面、人物补充设定、动作、情绪、对白、音效、图像/视频提示词。每页显示 10 镜。
4. **按段落生成草稿**：以空行分隔段落，一段一镜，默认 5 秒。明确是规则草稿，不做 AI 人物识别、不生成图片或视频、不产生付费请求。重建已有分镜前确认。
5. **导入**：本实现 v1 JSON；UTF-8 TXT/MD 追加为一个单集，保留文本，不执行 HTML/Markdown。第四批已增加 DOCX/PDF 文本提取、预览确认与按长度追加，需源码版 Python 后端及新增依赖，详见 `story-document-import.md`。
6. **导出**：完整工作室 JSON、可读 Markdown、当前集 CSV。CSV 对公式前缀做防护；导出是下载文件，不替代项目保存。
7. **从画布收集**：选择当前画布 `source-text` 或 `storyboard-script`，追加为新单集，原节点不改。源分镜时长支持数字秒数或 `5秒`/`5s`，复杂区间会报错而非静默猜测。
8. **生成分镜脚本节点**：先应用草稿，再调用现有 `createStoryboardScriptNodeData`，在工作室节点旁新建一份当前集快照。保留源工作室/单集 ID 标记，不覆盖既有分镜节点；重复操作明确创建新快照。
9. **参考图传递**：将已绑定且有效的源图像地址转换为旧分镜节点的 `@图片N` 与 `referenceImageRefs`。失效或不支持的引用不作为图片传递；文字设定仍保留。之后在分镜节点继续连线时，请核对其占位符顺序。

从工作室生成的分镜脚本节点仍使用旧版原有 AI 细化/媒体生成流程，模型、账号和计费由原系统管理。本批不自动触发模型调用。

## 数据和边界

数据位于 `node.storyWorkspace`，版本 `canvas-story-workspace.v1`，包含 title、synopsis、characters、scenes、episodes（script + shots）。第12批shots增加可选mediaRefs白名单（每镜最多图片/视频各一个，仅kind/nodeId），已接入normalize和JSON往返；旧代码可能丢弃该扩展，独立JSON不带所引用节点或媒体。第19批资料增加可选referenceImage白名单来源记录（version/nodeId/localPath/resultKey），配合原referenceNodeId，旧手动引用不强制迁移；旧代码可能丢弃该记录。只保存白名单字段；未识别的 JSON 版本报错。本版字段之外的扩展数据不承诺保留。

- 100 集；人物与场景各 200 项；每集 300 镜；合计 2000 镜。
- 每集正文 200000 字符；其他长文本字段 20000 字符；工作室数据及 JSON/TXT/MD 导入上限 4MB。DOCX/PDF 文件上限 8MB，另有解析资源限制。超限明确拒绝，不悄悄截断正文。
- 从画布收集标准分镜文本列，不迁移自定义列、角色图片占位符和源节点富文本格式；参考图片需重新绑定。
- 人物/场景引用的是源图片节点 ID，不打包图片。跨画布 JSON 导入后可能显示失效引用；本批不自动扫描磁盘补齐素材。
- 分镜脚本节点是快照，不是双向自动同步。可以手动收集为新单集，但不会自动回写覆盖。
- 本批窗口中文为主，节点创建菜单有中英文标签。
