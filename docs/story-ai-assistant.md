# 剧本 AI 助手：拆集、资料提取与分镜生成

第五批在已有剧本工作室内新增 AI 助手，复用项目的 `api/aiTextApi.js`。没有替换原文本生成 API、重写鉴权、增加后端路由或在节点中保存密钥。仍不是新版工作室完整移植。

## 入口与模型

剧本工作室 → 选择有正文的单集 → **AI 拆集 / 资料 / 分镜**。

第五批最初接入火山引擎；第九批已扩展为厂商/模型选择器，接入当前清单中支持纯文字的火山引擎、Agnes、APIMart、GRSAI、PPIO、RunningHub LLM，以及画布文本节点的 OpenAI/custom 兼容模型。仍排除图片必选模型与工作流，详见 `story-ai-providers.md`。

在项目原有设置中配置该厂商 API Key 和服务地址。请求继续经过原有 manifest、地址解析、鉴权与响应处理；如果配置了中转，则正文发送至该配置对应的服务，不一定是官方直连。没有在本批自动调用模型，也没有读取/导出用户密钥。

## 发送与费用

- 拆集/资料提取只发送当前单集正文及本次任务说明。第六批分镜模式可额外发送明确选择的资料名称、描述和创作要求；支持发送文字预览。均不发送整个工作室、其他单集、图片绑定或历史对话。
- 点击发送会再次确认厂商、模型、正文长度以及可能产生费用。不会自动重试、自动批量拆请求或自动请求修复 JSON。
- 单次最多 40000 个 UTF-16 字符、400 个自然段；格式化提示词最多 48000 字符。超限报错，不截断。
- 沿用既有文本 API 的等待策略，不显示虚构百分比；没有估算或保证实际费用。
- 本工作室 AI 通道只允许一个底层请求在等待。离开窗口或放弃预览不会提前释放该请求占用的提交锁；结束后才可显式再次发送。不影响其他原有画布生成通道。
- **“放弃本次结果”不是厂商任务取消**。既有 `generateText` 没有可复用的 AbortSignal 契约，本批不冒称能停止远端执行/计费。
- 超时/断网不代表厂商未收到请求；重发前先核对厂商记录，避免重复计费。
- 单次助手不具备跨刷新恢复；第七批队列可手动导出/导入快照，第八批可明确启用 IndexedDB 本地自动保存，但不是常驻后台任务中心。刷新可能丢失未提交或未导出的内存状态。项目数据不包含请求凭据或未合并的 AI 结果。

## AI 拆集方案

正文按空行编号，AI 仅返回集标题、摘要与起止段落编号，目标 1–12 集且不超过段落数。程序要求连续覆盖全文、顺序正确、无重叠/遗漏。

**新单集正文由原文区间直接复制，而不是采用模型改写的正文**，保留原有空白、换行和 Unicode 字符。程序检查所有新正文拼接后等于原文。摘要只用于预览，不回写正文。

预览确认后追加新单集，原单集和既有分镜全部保留；不会按原文自动生成镜头或视频。复制的原单集会占用工作室容量，如不再需要请人工确认后删除。

## 人物与场景资料

每类最多 40 项，每项包含名称、描述及 1–10 个引用段落编号。结果会展示模型描述和所引用原文，用户逐条勾选。

- 段落编号有效只代表结构校验通过，**不证明模型事实正确**；外观、身份、场景细节仍需人工核对。
- 同名比较采用 Unicode NFKC、去首尾空白、大小写归一；同名条目跳过，保留原手工描述和图片绑定，不自动合并覆盖。
- 未勾选条目不导入；新资料的图片引用为空，之后在资料页自行绑定。
- 引用段落用于本次审阅，不新增到现有资料持久化 schema 中。

## 格式错误与写入保护

原始 JSON 保留在本次窗口，可手动修正后点击 **校验当前 JSON（不收费）**。修改 JSON 会使上一份预览失效，必须重新校验才能确认。只接受 JSON 或一个完整 JSON 代码块，不执行文本中的 HTML、JavaScript、链接或工具调用。

确认追加前整体检查现有工作室的 100 集、200 人物/场景、4MB 等容量限制。失败不部分写入。源画布、草稿版本或节点内容改变时拒绝合并过期结果。

确认追加仅修改工作室草稿。仍需 **应用到项目 → 原有工程保存** 才能落盘；未确认、离开或放弃均不写入。已应用的更改仍使用原有画布撤销/重做。

## 源码与验证

- `api/storyAiApi.js`：允许的模型来源、复用 `generateText`。
- `src/modules/storyWorkspace/storyAiModel.js`：提示词、段落映射、JSON 校验、冲突处理及原子追加。
- `src/modules/storyWorkspace/storyAiRequestGate.js`：单请求占用锁，不在 UI 取消时提前释放。
- `src/modules/storyWorkspace/StoryAiPanel.js`：费用确认、请求、JSON 修正、引用原文预览和勾选合并。
- `StoryWorkspaceEditor.js`、独立 CSS：工作室接入与生命周期保护。
- 两份 `.test.js`：14 项离线测试源码，包含原文完整性、错误格式、资料冲突、容量与单请求约束。

第五批实际检查：7 个新增/修改 JavaScript 文件通过目标机 `node --check`，相对导入文件存在；工作室目录和 API 目录的现有编辑器 error 诊断为 0。14 项测试只有源码，未执行；未运行构建、应用或真实付费模型请求。静态检查不等于厂商端到端、界面和计费行为验收通过。

手动验收：缺密钥、有效模型配置、显式发送确认、有效/无效 JSON、修正后校验、超限、重复点击、等待时离开、网络中断、同名资料、未勾选项、源数据变更、确认后应用/保存/重开，以及原 DOCX/PDF 导入不回归。
